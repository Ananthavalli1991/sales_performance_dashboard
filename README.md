#  Sales Performance Dashboard
Sales performance analysis and interactive Power BI dashboard using Python, Pandas, and DAX.


## Project Overview

This project analyzes sales performance, profitability, product performance, customer behavior, and regional sales using Python, Pandas, and Microsoft Power BI.

The project demonstrates data cleaning, exploratory data analysis, business insights, and interactive dashboard development.

**Note:** This project uses synthetic sample data created for educational and portfolio purposes. It does not represent actual company transactions.

## Tools and Technologies

* Python
* Pandas
* Microsoft Power BI
* DAX
* Excel and CSV

## Project Objectives

* Analyze overall sales and profit.
* Compare sales performance across regions.
* Identify top-performing and low-performing products.
* Analyze profit by product category.
* Examine monthly sales trends.
* Understand customer sales and profitability.
* Present key performance indicators through an interactive dashboard.

## Key Performance Indicators

* Total Sales
* Total Profit
* Total Quantity Sold
* Profit Margin

## Key Findings

* Total Sales: 4,818,056.60
* Total Profit: 1,387,169.84
* Total Quantity Sold: 22,327
* Profit Margin: 28.79%
* Best-performing region by sales: South
* Top-selling product by sales: Laptop

These findings are based on the synthetic dataset used in this project.
